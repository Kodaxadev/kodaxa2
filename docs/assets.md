# Asset sources

## Original artwork

`public/images/kodaxa-knot.webp`: generated for this project with the built-in image-generation tool. Brief: a floating polished black-chrome four-loop ribbon knot, subtle emerald reflections, warm ivory studio background, no text or branding. Encoded to WebP for delivery. CSS adds slight floating and pointer response; the delivered artwork is a raster image, not a real-time 3D model.

## Stock photography

The following source pages were inspected live on 2026-09-04 and identified the images as free under the [Unsplash License](https://unsplash.com/license). Local copies are used for consistent loading.

- `public/images/cafe.webp` — Long Chung, [Sunlight streams through a window onto two bar stools](https://unsplash.com/photos/sunlight-streams-through-a-window-onto-two-bar-stools-EGU0c37idAA). [Original asset](https://images.unsplash.com/photo-1774521044355-508615f287ca?auto=format&fit=crop&w=1400&q=85).
- `public/images/architecture.webp` — Janelle Hiroshige, [Mid-century modern house with palm trees](https://unsplash.com/photos/mid-century-modern-house-with-palm-trees-1OWdij5G6qw). [Original asset](https://images.unsplash.com/photo-1618360945198-3460f54d2ee5?auto=format&fit=crop&w=1400&q=85).

The photographs illustrate independent fictional brand concepts. Neither photographer, venue, nor property is represented as a Kodaxa client.

## Typography and icons

Manrope and Geist Mono are loaded through the generated framework's Google Fonts integration. [Google Fonts FAQ](https://developers.google.com/fonts/faq) describes open-source font licensing; [Manrope](https://fonts.google.com/specimen/Manrope) and [Geist Mono](https://fonts.google.com/specimen/Geist+Mono) provide the font families. Icons use the installed [Lucide library](https://lucide.dev/license). The favicon is a simple original letter K.
